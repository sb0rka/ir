# Сгенерированный Go-контракт

Пакет на домен, повторяет раскладку `api/paths`. Ничего здесь не редактируется:
файлы `*.gen.go` перезаписываются `task generate-go`.

| Пакет | Что внутри |
|---|---|
| `shared` | словари, конверт ошибки, общие параметры и ответы |
| `spec` | вся спека, вкомпилированная в бинарь — для `/swagger` и `/openapi.json` |
| остальные | по домену из `api/paths`: модели, `StrictServerInterface`, роутер |

Домены ссылаются на `shared` через `import-mapping` генератора, поэтому общие
типы не дублируются между пакетами.

Раскладка выбрана из-за читаемости diff'ов: правка одной ручки меняет один
файл на несколько сотен строк, а не общий на восемь тысяч.

Соответствие спеке проверяет `task check-generated` — перегенерирует и падает,
если результат отличается от закоммиченного.
