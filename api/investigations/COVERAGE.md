# Покрытие требований Техлаб

Текущий объём контракта: 20 путей, 32 операции, 5 доменов.

Важно: контракт и реализация — разные статусы. Инфраструктура сервиса работает,
но все доменные операции пока возвращают `501 not_implemented`.

## Нефункциональные требования

- **Аутентификация:** Ed25519 JWT платформы, audience `api.local`.
- **Авторизация:** субъект без `role_bindings` получает `403`. Разграничение
  L1/L2/lead/admin по операциям ещё нужно реализовать.
- **Project isolation:** обязательный `X-Project-ID` проверяется по `role_bindings`;
  `project_id` хранится на общих для проекта сущностях и проверяется составными FK. Узлы и рёбра
  получают project scope через `investigation_id` и не дублируют `project_id`.
- **Воспроизводимость:** контракт хранит `source_ref` и evidence для рёбер;
  затяжка и правила ещё не реализованы.
- **Недоступность источника:** ответ `502 source_unavailable` описан, но адаптеров
  источников пока нет.

## Вне v0.1

- внутренний MCP-контур агента;
- автосвязывание, интеграции источников и обогащение;
- отчёты и пакет реагирования;
- аудит, метрики и API администрирования;
- сквозной триаж и поиск вне расследования;
- синхронизация с SOM. Схема хранит внешние связи investigation↔workspace и graph node↔issue,
  но вызовы SOM и проверка существования внешних UUID ещё не реализованы.
